# Low-Level Cryptographic Primitives in Assembly (MASM x86)

Репозиторий содержит коллекцию низкоуровневых криптографических примитивов, алгоритмов хеширования и контроля целостности, разработанных на языке ассемблера **MASM (Microsoft Macro Assembler)** для архитектуры x86 в рамках академического интенсива «Ассемблер в задачах защиты информации» (Факультет Кибербезопасности, СПбГУТ).

## 📌 Перечень реализованных алгоритмов

### 1. Линейный конгруэнтный генератор (LCG)
* **Описание:** Алгоритм генерации псевдослучайных чисел (ПРСЦ), основанный на линейном рекуррентном соотношении:
  $$X_{n+1} = (a \\cdot X_n + c) \\pmod m$$
* **Параметры реализации:**
  * Множитель ($a$): `1103515245`
  * Приращение ($c$): `12345`
  * Модуль ($m$): $2^{31}$ (реализовано через наложение битовой маски `7FFFFFFFh`).
* **Особенности:** Оптимизировано по скорости выполнения с использованием регистра `EAX` и прямой побитовой маскировки вместо тяжелых инструкций деления `div`.

### 2. Модуль 8-битной контрольной суммы (Checksum)
* **Описание:** Простейший алгоритм проверки целостности данных, выполняющий арифметическое суммирование кодов символов строки.
* **Особенности:** Алгоритм работает с входной строкой байт произвольной длины, накапливая сумму по модулю 256 в 8-битном регистре `BL`. Внутри цикла чтения используется оптимизированная цепочечная строковая инструкция процессора `lodsb` и счетчик итераций `loop`.

### 3. Блочный шифр TEA (Tiny Encryption Algorithm)
* **Описание:** Симметричный блочный криптоалгоритм, построенный на основе сети Фейстеля.
* **Параметры реализации:**
  * Размер блока: 64 бита (разделен на два 32-битных регистра данных `v0` и `v1`).
  * Размер ключа: 128 бит (передается через четыре 32-битных регистра/слова `k0`, `k1`, `k2`, `k3`).
  * Число раундов: 32 цикла (полный цикл шифрования).
  * Раундовая константа (Золотое сечение): $\\delta = \text{9E3779B9h}$.
* **Особенности:** Код полностью защищен от простейших атак по времени (Timing-атак), так как не содержит условных переходов (`jcc`) в раундовой функции — вычисления занимают строго константное время вне зависимости от ключа.

### 4. Табличные замены Rijndael S-Box (AES component)
* **Описание:** Модуль нелинейной подстановки байт, являющийся ключевым этапом (`SubBytes`) в государственном стандарте симметричного шифрования AES (Rijndael).
* **Особенности:** Для достижения максимальной производительности вместо программного вычисления инверсий в полях Галуа $GF(2^8)$ применена статическая таблица замен (S-Box) объемом 256 байт. Доступ к элементам таблицы реализован на аппаратном уровне с помощью высокоэффективной ассемблерной инструкции `xlat`, выполняющей табличную трансляцию базового адреса буфера по смещению.

### 5. Вычисление упрощенного хеша SHA-1 (1 раунд)
* **Описание:** Криптографическая хеш-функция, предназначенная для формирования «отпечатка» сообщения. В рамках проекта реализован 1 полный раунд сжатия, состоящий из 20 последовательных шагов.
* **Параметры реализации:**
  * Входной блок данных: 512 бит (массив слов расширенного сообщения от `w0` до `w3` и далее).
  * Внутреннее состояние: пять 32-битных регистров инициализации `h0`–`h4`.
  * Раундовая константа: $K = \text{5A827999h}$.
* **Особенности:** Интенсивно используются регистровые циклические сдвиги влево `rol` и побитовые нелинейные функции. Шаг сжатия организован с помощью декрементируемого цикла `dec ecx / jnz sha1_loop`.
